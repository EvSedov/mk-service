# Сайт компании МК Сервис

## Обзор Проекта

Проект представляет собой разработку веб-сайта для компании, специализирующейся на **продаже широкого ассортимента строительных материалов и инструментов**. Сайт призван служить витриной продукции, предоставлять информацию о компании, ее брендах и клиентах, а также предлагать возможность запроса коммерческого предложения.

### Цели Проекта

- Презентация полного ассортимента строительных материалов и инструментов.
- Демонстрация партнерств с известными брендами и списка клиентов для повышения доверия.
- Предоставление контактной информации и возможности обратной связи.
- Увеличение количества запросов коммерческих предложений от потенциальных клиентов.

## Продукт и Целевая Аудитория

### Продукт:

Широкий ассортимент строительных материалов и инструментов, включая:

- Сварочные материалы (электроды, проволока)
- Средства индивидуальной защиты (перчатки, респираторы, каски, очки)
- Абразивные и пильные материалы (отрезные, шлифовальные, алмазные диски)
- Ручной и электроинструмент (лопаты, метлы, уровни, рулетки, дрели, шуруповерты, перфораторы, строительные фены)
- Металлические изделия (проволока вязальная, сетка рабица, стропы, крепеж: гвозди, саморезы, дюбеля, заклепки, стяжки)
- Химические строительные материалы (грунтовки, эмали, растворители, цинол, монтажная пена, герметики, очистители, мастики, праймеры, рулонная гидроизоляция)
- Специализированные расходные материалы (патроны и дюбеля для монтажного пистолета)

### Целевая Аудитория:

Основная целевая аудитория — это **B2B-сектор**, включая:

- Строительные организации и подрядчики
- Промышленные предприятия
- Оптовые и розничные торговые компании в сфере строительных материалов
- Возможно, крупные частные застройщики

## Техническая Составляющая Проекта

### Технологический Стек:

- **Фронтенд:** Vue.js 3 (для интерактивного и динамичного пользовательского интерфейса)
- **Сборщик:** Vite (для быстрой разработки и оптимизации сборки)
- **Стилизация:** Tailwind CSS (для быстрой и адаптивной верстки), PostCSS, Autoprefixer
- **Линтинг и форматирование кода:** ESLint, Prettier (для поддержания чистоты и единообразия кода)
- **Система контроля версий/хуки:** Husky, Lint-staged (для автоматической проверки кода перед коммитами)
- **Язык программирования:** JavaScript (основной язык разработки)

### Структура проекта:

- `App.vue`, `main.js` - основные точки входа приложения.
- `src/assets/` - содержит статические ресурсы:
  - `icons/` - иконки брендов, клиентов, продуктов, а также общие иконки (телефон, чат, PDF).
  - `images/` - фоновые изображения и логотипы компании.
  - `styles/` - базовые и основные CSS-стили.
- `src/components/` - организованные компоненты UI:
  - `atoms/` - мельчайшие компоненты (иконки, логотипы, кнопки).
  - `molecules/` - более сложные компоненты, состоящие из атомов (карточки клиентов/продуктов, формы).
  - `organisms/` - крупные, секционные компоненты, объединяющие молекулы (футер, хедер, основные разделы сайта).
    - `sections/` - выделенные разделы сайта, такие как `MksBrandsLogosSection`, `MksClientLogosSection`, `MksHero`, `MksInfo`, `MksProductsSection`, `MksTeam`.
  - `pages/` - компоненты, представляющие целые страницы (`HomePage.vue`).
  - `templates/` - шаблоны страниц (`PageLayout.vue`).

## Настройка Проекта и Разработка

### Рекомендуемая настройка IDE

[VSCode](https://code.visualstudio.com/) + [Volar](https://marketplace.visualstudio.com/items?itemName=Vue.volar) (и отключите Vetur).

### Настройка конфигурации

Смотрите [Справочник по конфигурации Vite](https://vite.dev/config/).

### Установка проекта

```sh
npm install
```

### Компиляция и горячая перезагрузка для разработки

```sh
npm run dev
```

### Компиляция и минификация для продакшена

```sh
npm run build
```
